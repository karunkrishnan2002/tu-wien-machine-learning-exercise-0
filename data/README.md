# Dataset files (not included)

The original ARFF datasets are intentionally not committed in this repository. They may be large and can be subject to the original provider's terms and the course's sharing rules.

Place the two course dataset files in this folder using these exact filenames (no extension is required):

- `Credit_Card_Fraud_Classification`
- `Autism-Screening`

If your downloaded files have an `.arff` extension, either keep the extension and update the filename references in the scripts, or rename the files to the exact names above. Do not modify the original data values.

Obtain the datasets from the source locations specified in the TU Wien course materials / assignment instructions. Check the dataset licence and attribution requirements before redistributing them.
