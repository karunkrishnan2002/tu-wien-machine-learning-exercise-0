# LinkedIn project post (ready to edit)

I’m sharing a dataset exploration project completed as part of the Machine Learning course at TU Wien.

The project compares two classification datasets — Credit Card Fraud Classification and Adult ASD Screening — and focuses on understanding the data before any modelling begins.

**What I worked on:**
- Inspected dataset dimensions, attributes, data types, and missing values using Python and pandas.
- Analysed target-class distributions and identified class imbalance in the fraud dataset.
- Explored numerical ranges and distributions, including transaction amounts and age.
- Reviewed categorical feature distributions and discussed nominal, ordinal, interval, and ratio measurement scales.
- Flagged a suspicious age value in the ASD dataset for investigation rather than changing it without evidence.
- Created reproducible Python scripts and visualisations, with setup and run instructions in the repository.

**Tools:** Python, pandas, Matplotlib, ARFF, GitHub, VS Code.

The repository includes the project overview, scripts, generated figures, and report files. The raw datasets are not redistributed; instructions explain how to obtain and place them locally in accordance with the course and dataset terms.
